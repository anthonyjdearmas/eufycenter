To launch API:
1. cd /Users/anthonydearmas/Desktop/EUFY Simple Center/api
2. node index.js

To launch UI
1. cd /Users/anthonydearmas/Desktop/EUFY Simple Center/ui
2. node server.js


After starting both servers, you should see console messages indicating that they're running.
Open your browser and navigate to the UI server (likely http://localhost:8080).
The UI should load, and when you click the "Fetch Data" button, it should connect to the API at http://localhost:3000.
